# Arena Art Assets

Place the visual-slice arena art here.

## Primary Arena

Expected filename:

```text
schoolyard_arena.png
```

Recommended source size:

```text
2048 x 1280 px
```

Recommended composition:

- Top-down or slightly tilted 2D schoolyard arena.
- Full playable area visible in landscape.
- Basketball court markings integrated into the artwork.
- Props around edges, not in the center path.
- Leave right side readable behind Punch/Special controls.
- No text, school names, logos, or real-world identifying marks.

Unity import:

- The scene builder imports this as a Sprite.
- Pixels per unit: `128`.
- If this file is missing, Unity falls back to generated prototype art.
